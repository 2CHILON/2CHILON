## 👨‍💻 About Me

**BSc Mathematics and Computer Science** graduate at  **JKUAT**, Kenya, with a strong focus on **backend engineering** ,  **DevOps** and **Aws**.

I learn by building. Instead of only using tools, I like to understand how they work underneath, which is why I've built a relational database engine, an HTTP load balancer, and a shell in my own repos.

- 🎯 **Targeting:** Backend Developer and DevOps Engineer roles
- 🔭 **Currently:** Studying data structures and algorithms in Python, deepening JavaScript, and exploring the PocketBase codebase
- 🌱 **Always learning:** distributed systems, containers, orchestration, and database internals
- 💬 **Ask me about:** Go, Spring Boot, Docker, Kubernetes, CI/CD pipelines
